# Материалы страницы Genesis на Poki

| Файл | Куда | Требование Poki |
|---|---|---|
| `thumbnail_1024.png` | статичная обложка (загружать её) | квадрат, не меньше 628×628, на весь кадр, без скруглений |
| `thumbnail_628.png` | то же в минимальном размере — проверить, читается ли на маленькой плитке | |
| `animated_thumbnail_1080.mp4` | анимированная обложка (нужна к Soft Release) | 1:1, 1080×1080, 50 fps, 5 с, MP4, без звука, начинается со статичной обложки |
| `texts_en.md` | название, описание, управление (основной язык) | |
| `texts_ru.md` | русская версия текстов | |

Картинки и видео нарисованы из текстур и моделей игры (без чужих брендов, цвета не близки к фону Poki #83FFE7).
Анимированная обложка — черновая: Poki просит показывать настоящий геймплей, поэтому к Soft Release лучше
записать 2–3 коротких сцены в самой игре (см. `../POKI.md`, раздел «Обложки») и склеить их, начиная с этой картинки.
