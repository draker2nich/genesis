# Genesis — страница Poki (русский)

Poki показывает игру прежде всего международной аудитории — основной текст английский (`texts_en.md`).
Русский — для русскоязычной версии страницы, если Poki её попросит.

## Название

```
Genesis
```

## Одной строкой

```
Строй заводы и автоматизируй добычу на воксельной планете
```

## Описание

```
Ты просыпаешься в старом бункере на дикой воксельной планете — и превращаешь её в работающий завод.

Сначала всё руками: рубишь деревья, крафтишь кирку на верстаке, куёшь первые детали в коротких мини-играх. Каждый процесс, сделанный вручную, открывает его автоматизацию — паровые буры на бесконечных залежах, конвейеры, манипуляторы, электричество и сеть хранения, которая крафтит сама.

• Огромный мир: 15 биомов, реки, горы, парящие острова, пещеры и руины
• Эпохи от дерева и камня до пара и электричества — с деревом знаний
• Машины, ленты, трубы и провода, которые соединяешь сам
• Животные для фермы и ночные существа, с которыми не заскучаешь
• Карта с метками, справочник рецептов, статистика производства
• Мир сохраняется автоматически в браузере
```

## Управление — компьютер

```
Мышь — осмотр · WASD — ходьба · Пробел — прыжок · Shift — бег
Удерживать ЛКМ — ломать / бить · ПКМ — поставить блок, открыть машину, съесть
1–9 или колесо — выбор предмета · E — инвентарь и крафт · J — рецепты
K — что делать дальше · M — карта · R — повернуть машину · Q — выбросить
Esc — пауза
```

## Управление — телефон и планшет

```
Левая часть экрана — джойстик ходьбы (до края — бег)
Правая часть — вести пальцем, чтобы осмотреться · Тап — поставить блок / открыть машину / съесть
Удерживать палец — ломать или бить · Кнопки — прыжок, вниз, сумка, рецепты, карта, пауза
Тап по предмету на панели внизу — выбрать его
```
