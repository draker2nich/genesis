# Материалы страницы Genesis в Яндекс Играх

| Файл | Поле черновика | Размер |
|---|---|---|
| `icon_512.png` | Иконка | 512×512 PNG |
| `cover_800x470.png` | Обложка | 800×470 PNG |
| `hero_1560x520.png` | Hero Image | 1560×520 PNG |
| `texts_ru.md` | Тексты на русском | длины проверены |
| `texts_en.md` | Тексты на английском | длины проверены |

Картинки нарисованы из текстур и моделей игры. На обложке и hero только логотип «GENESIS» без других надписей,
поэтому они подходят для обоих языков.

Скриншоты (минимум 2) и горизонтальное видео (до 28 с) нужно снять в самой игре — см. раздел «Публикация» в `../YANDEX.md`.
